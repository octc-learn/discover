# Discover OCTC maintenance instructions

This is a student-facing public prototype. Preserve OCTC branding, accessible text, mobile-first navigation, and restrained analog styling. Do not invent events, dates, locations, registrations or Merit status. Use only approved public materials.

Edit `data/discover.json` for routine changes. Each event uses a unique id, title, ISO date (YYYY-MM-DD), optional inclusive end date, time (Central, human-readable), location, category, description, optional flyer filename, merit boolean and kind (`event` or `notice`). For an ongoing event with unknown start, leave date blank and give the confirmed end. Never assume Merit eligibility. Add separate records for confirmed recurring dates. Flyers go in `flyers/`. Keep essential flyer details in accessible text. Verify public registration links before adding them.

Activities use title, description, duration, url, merit and optional end. Videos use title, description, url and optional end; use approved captioned media. The video section is hidden if empty. Do not publish private student data or restricted meeting links. Avoid overwriting design files for ordinary content updates. Review changes and verify the published site before announcing it.
