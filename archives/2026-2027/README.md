# Discover Rewind · 2026–2027

Place approved public campus photos in this folder. Use descriptive filenames. Add curated entries to `../index.json`; the site automatically groups them by year. Do not upload private images, unapproved student media, or personal information. Captions must be accurate and alt text must describe the image. Videos should use approved public captioned media links. Do not automatically turn expired event announcements into memories.

Example entry structure (not a real entry):

```json
{"id":"unique-id","date":"YYYY-MM-DD","title":"Event name","caption":"Accurate description of what happened","image":"archives/2026-2027/photo.jpg","alt":"Description of the photo","videoUrl":"","videoCaptioned":false,"approved":false}
```

Set `approved` to true only after institutional media/publication approval is confirmed. Do not commit unapproved media to this public repository even if the entry is hidden.
